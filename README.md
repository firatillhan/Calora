# Calora

A calorie and nutrition tracking app built with SwiftUI and SwiftData, with HealthKit integration.

## Features

- Daily calorie, protein, carbohydrate, and fat tracking
- Automatic reading of active burned calories via HealthKit
- Photo-based food/meal entry list
- Calendar view showing color-coded status (under/over goal) for past days
- BMR/TDEE calculation based on personal info (height, weight, age, activity level, goal type)
- Daily goal automatically recalculated for today whenever the profile is updated

## Technologies Used

- SwiftUI
- SwiftData
- HealthKit
- SDWebImageSwiftUI
- PHP + MariaDB (backend API)

## Requirements

- Xcode 15+
- iOS 17+
- HealthKit permission (for active calorie data)
